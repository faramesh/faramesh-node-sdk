# Security Policy

Do not open public issues for vulnerabilities in the Faramesh TypeScript SDK.

Preferred reporting paths:

- GitHub Security Advisory: https://github.com/faramesh/faramesh-typescript-sdk/security/advisories/new
- Email: security@faramesh.dev

Reports should include affected versions, reproduction steps, impact, and any
suggested remediation.

Security reports are acknowledged within 3 business days and receive an initial
assessment within 7 business days.
